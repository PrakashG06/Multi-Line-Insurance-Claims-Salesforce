# Multi-Line-Insurance-Claims-Salesforce

Salesforce-based solution to manage Vehicle, Property and Life
insurance policies and claims. Includes Record Types, Field Sets,
Screen Flow, Apex premium calculation, claim routing, approval
process and an LWC Claims Dashboard.
